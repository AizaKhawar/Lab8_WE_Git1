LAB TASK 2 - Upload the project to GitHub (run in Git Bash)
============================================================

STEP 1 (browser): github.com -> New repository
   Name: Lab8_WE_Git1   | Public
   (Tick "Add a README" ONLY if you want to follow Step 9 below;
    otherwise leave it empty - simpler.)

STEP 2: one-time identity setup
   git config --global user.name  "Your Name"
   git config --global user.email "you@example.com"

STEP 3: go into the extracted project folder
   cd /d/Lab8_WE_Git          (Git Bash path style for D:\Lab8_WE_Git)

STEP 4: initialise, stage, commit
   git init
   git status
   git add .
   git commit -m "Initial commit: responsive CSS Grid product gallery"

STEP 5: rename branch and link GitHub
   git branch -M main
   git remote add origin https://github.com/<your-username>/Lab8_WE_Git1.git
   git remote -v

STEP 6: push
   git push -u origin main
   (If the repo was created WITH a README and push is rejected, run first:
      git pull origin main --allow-unrelated-histories
    then push again. If a merge editor opens, save and close it.)

STEP 7: verify
   git status
   git log --oneline
   Refresh the GitHub page - index.html, style.css, README.md must appear.

OPTIONAL - branch demo (as in the lab manual)
   git checkout -b lab9_WE
   git branch
   git switch main

TROUBLESHOOTING
   - Wrong URL:  git remote set-url origin https://github.com/<user>/Lab8_WE_Git1.git
   - Auth asked: sign in via the browser popup, or use a Personal Access Token as password.
   - Replace <your-username> with your real GitHub username.
